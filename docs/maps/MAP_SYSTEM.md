# Map System

Игра не привязана к одной карте. Карта = **Map Definition** (`map.json`) + растровые данные. Все
механики используют общий движок симуляции; у карты — только геометрия и параметры.

## 1. Формат карты
Каталог `godot/data/maps/<id>/`:

| Файл | Содержимое |
|---|---|
| `map.json` | определение карты (ниже) |
| `terrain.png` | RGB8, пиксель = тайл. **R**: биты 0–3 — код рельефа, бит 4 — река; **G**: высота 0–255 (для отрисовки рельефа); **B**: 0 |
| `preview.png` | превью для экрана выбора (≤ 400 px по ширине) |

Коды рельефа (`scripts/world/map_data.gd`): `0` глубокий океан, `1` мелководье, `2` озеро, `3` равнина,
`4` лес, `5` холмы, `6` горы, `7` пустыня, `8` тундра, `9` ледник (непроходим).

`map.json`:
```json
{
  "id": "pelagia", "category": "fictional",
  "name": {"ru": "Пелагия", "en": "Pelagia"},
  "description": {"ru": "…", "en": "…"},
  "features": ["archipelago", "straits", "naval"],
  "width": 1600, "height": 900, "k_lin": 1.0,
  "recommended_bots": [8, 24], "max_bots": 32,
  "nations": [{"id": "n1", "name": {"ru": "…", "en": "…"}, "flag": "", "x": 120, "y": 340}],
  "balance": {"tribes_default": 40},
  "stats": {"land_tiles": 0, "continents": 0, "islands": 0},
  "source": "VolnaLabs original (generated from authored spec)", "license": "AGPL-3.0"
}
```
`flag` — код файла в `godot/assets/flags/` или пусто (процедурный флаг от seed). `stats` заполняет
инструмент выпечки/экспорта. Карта добавляется **только** новым каталогом — UI ничего не перечисляет
вручную: `MapRegistry` (autoload) сканирует `res://data/maps/*/map.json`.

Производные данные (`MapData.derive()`): маска суши, акватории (`water_body`, океан = 1), побережье,
массивы суши (`landmass`, размер каждой), списки прибрежных тайлов по акваториям. Считаются при загрузке.

| id | Тип | Размер | Источник |
|---|---|---|---|

## 3. Генератор миров (`scripts/map_generator/`)
Параметры (`GenParams`): `seed`, `preset`, `width/height` (S 800×400, M 1200×600, L 1600×800, XL 2000×1000),
`continents`, `islands`, `land_percent`, `inland_seas`, `river_density`, `roughness`, `mountains`,
`symmetry` (none / mirror / rotate2 / rotate4), `start_positions`.

Пресеты (`data/maps/generator_presets.json`): **Continents, Archipelago, Pangaea, Island Chains,
Ring World, Random World** — наборы параметров и тип «маски масс суши».

Конвейер (всё детерминировано от seed: `SimRng` + `FastNoiseLite` с фиксированными seed):
1. **Маска суши**: центры масс суши по пресету (континенты — разнесённые Poisson-точки; пангея —
   одна большая; цепи — вдоль дуг; кольцо — тор вокруг центра; архипелаг — много малых), к каждой —
   радиальная функция с доменным искажением шумом; плюс fBm-шум для береговой линии.
2. **Уровень моря** по квантилю, чтобы получить ровно `land_percent` суши.
3. **Горы**: хребты — гребенчатый (ridged) шум, усиленный по линиям между центрами масс («швы плит»)
   и умноженный на `mountains`; высота → холмы/горы.
4. **Внутренние моря**: вырезание впадин внутри крупных масс суши (`inland_seas`).
5. **Климат**: широта + высота + влажность (шум) → тундра / лес / равнина / пустыня.
6. **Реки**: от горных истоков вниз по высоте до моря/озера, число по `river_density`.
7. **Чистка**: острова < 30 тайлов и озёра < 20 тайлов удаляются; мелководье у берега.
8. **Симметрия**: зеркалирование / поворот поля высот до порога моря.
9. **Анализ** (`map_analysis.gd`): массы суши, число континентов (≥ 2 % суши) и островов, акватории.
10. **Стартовые позиции** (`start_positions.gd`): кандидаты на суше, вес = полезная земля в радиусе 30
    (ценность рельефа) и удалённость от моря/края; жадный Poisson-выбор с минимальной дистанцией
    `sqrt(land/starts)·0.6`; итоговая оценка справедливости — разброс ценности земли вокруг стартов.
    Если массив суши слишком мал для старта, старт переносится.
11. **Имена и флаги**: генератор имён из слогов (`data/nations/name_pools.json`), процедурный флаг
    (полосы/крест/круг, цвета от seed).

Один и тот же набор параметров даёт байт-в-байт одинаковый `terrain` (проверяется тестом по хешу).
Генерированные карты в сохранениях хранятся как параметры + seed + хеш.

## 4. Вымышленные карты
Спецификация (`godot/data/map_specs/*.json`) задаёт крупные формы вручную: массы суши (центр, радиусы,
вытянутость, поворот, сила искажения), хребты (полилинии), внутренние моря, проливы (каналы), а также
пресет климата и seed. `scripts/tools/bake_maps.gd` прогоняет их через тот же генератор и записывает
`data/maps/<id>/terrain.png`, `preview.png`, `stats` и старты. Формы — оригинальные.

## 5. Экран выбора карты
Плитки с превью, название, описание, размер, число континентов и стартов, особенности, рекомендуемое
число противников. Кнопка **«Случайный мир»** — генерация со случайным seed и пресетом; отдельный экран
**«Генератор миров»** — все параметры с живым превью.

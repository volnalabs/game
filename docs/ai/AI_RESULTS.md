# Результаты AI-симуляций

Все цифры — из `scripts/tools/ai_sim_cli.gd` на финальном коде ветки (31.10.2026), карты сгенерированы
по seed партии (`gen:<пресет>:S`, 800×400), 8 государств (10 в режиме характеров), без племён,
победа — 60 % суши или уничтожение всех, лимит 9000 тиков (15 игровых минут). Группы чередуются
по стартам, ресурсы у всех одинаковые. Полные отчёты: `user://ai_sim/<режим>_<seed>.json`.

Повторить:

```bash
GODOT=$(tools/get_godot.sh)
$GODOT --headless --path godot -s res://scripts/tools/ai_sim_cli.gd -- --games 20 --map gen:continents:S --bots 8 --mode strategic_vs_legacy --seed 1000
```

Колонки: победы (доля партий, где победитель из группы), выживаемость, средняя доля суши в конце,
среднее время жизни (тики), атаки (завершённые атаки на государства, включая контратаки) и доля
успешных (≥ 20 тайлов), заработано золота, уплачено содержания армии.

## Стратегический AI (Normal) против старого AI RoWorld (Normal)

| Серия | Победы | Выживаемость | Доля суши | Жизнь | Золото |
|---|---|---|---|---|---|
| Континенты, seed 1000–1019 (финал) | 45 % / 55 % | **54 % / 44 %** | **13,8 % / 11,2 %** | **3579 / 3163** | **2,28M / 1,84M** |
| Континенты, seed 1000–1039 (раньше) | 45 % / 55 % | 54 % / 48 % | 13,6 % / 11,3 % | 4078 / 3473 | 3,19M / 1,81M |
| Континенты, seed 100–119 | 60 % / 40 % | 64 % / 42 % | 16,2 % / 8,8 % | 5091 / 3760 | 3,97M / 2,12M |
| Архипелаг, seed 4000–4019 (финал) | 35 % / 65 % | 66 % / 74 % | 10,2 % / 14,8 % | 6096 / 6183 | 4,05M / 3,87M |

**Вывод.** На континентальных картах стратегический AI во всех сериях выживает чаще, живёт дольше и
строит более сильную экономику, а средняя доля суши выше в 3 из 3 больших серий. По числу побед
(победитель один на партию) — паритет 45–60 %; критерий плана «≥ 65 % побед» **не достигнут**.
На архипелагах старый AI пока сильнее (он чаще и проще высаживает десанты).

Характеры играют измеримо по-разному (тест `test_personalities_play_differently`): агрессивные
воюют в 3 раза чаще оборонительных. **Агрессивный характер слишком безрассуден** — гибнет первым;
его веса нужно перекалибровать (известное ограничение).

## Как измерения меняли AI
См. `docs/ai/AI_DESIGN.md §12`. Ключевые находки: солдаты должны стоить столько, сколько времени
нужно на их восстановление; минимальный домашний резерв; обучение на исходах атак; контратака
вместо «удержания»; кулдаун наступательных решений (иначе бот, думающий каждые 5 тиков, распыляет
армию); «давление застоя» против патов полных армий; поиск своих побережий по спискам побережья
(государство, владеющее целым островом, не имеет сухопутной границы).

## Дипломатия (Phase 2F)
Подробно — `AI_DESIGN.md` §16. strategic vs legacy, 90 игр (seed 900–989): победы стратегического AI
55 → 53 из 90, земля 16.0 → 15.4 %, выживание 62 → 54 %; hard vs easy, 30 игр (seed 600–629, Fair):
hard 67 → 70 % побед, земля 15.5 % против 9.5 % (до 2F 14.9 % / 10.1 %). За 90 игр — 66 договоров,
0 предательств, 0 приказов, отклонённых из-за договоров. Команды проверяются `--teams 2`
(`tests/ai/test_diplomacy_ai.gd`). Серии отбросили три идеи: доверие к партнёрам (снижение их
угрозы), запрет атак при ожидающем предложении и «место для роста» без учёта выгоды атаки.

## Интеграция всех систем (Phase 2G)
Шумовая проба (лишний вызов ГСЧ за цикл, код до 2F): 53 / 90 побед против 55 / 90 — разброс серии из
90 игр около ±5 побед и ±0.08 выживания. После включения оружия в настоящих партиях и проверки мест
построек: strategic vs legacy (90 игр) 55 / 90, земля 16.1 % / 8.9 %; hard vs easy (30 игр) 63 %,
13.9 % / 11.1 %; в большой интеграционной серии 1–13 ударов за партию (было 0), отклонённых приказов на
постройку 14 вместо ~100. Подробно — `AI_DESIGN.md` §17.

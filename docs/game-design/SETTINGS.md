# Настройки (Phase 2G)

Хранятся в `user://settings.cfg` (`Settings`, `scripts/core/settings.gd`); любое изменение применяется
сразу (`Settings.apply()` → сигнал `changed`, партия подхватывает его без перезапуска) и сохраняется.
Экран — `scripts/ui/screens/settings_screen.gd`, четыре вкладки.

| Вкладка | Что есть |
|---|---|
| Общие | язык, отладка AI (F3), подсказки и их сброс |
| Изображение | масштаб интерфейса, анимации, качество эффектов, цвета карты (с примером цветов) |
| Звук | общая громкость и по категориям с пробным звуком, без звука в фоне (`docs/game-design/AUDIO.md`) |
| Управление | прокрутка у края экрана, переназначение клавиш, сброс |

## Клавиши
Реестр действий — `scripts/core/keys.gd` (`Keys.ACTIONS`): пауза, скорость, сила атаки, подтверждение,
строительство, зоны, камера домой, скрыть интерфейс, сохранение, справочник, отладка AI, движение
камеры, быстрые постройки 1–6. Каждое действие — InputMap-действие `tf_<id>` по **физическим** клавишам
(WASD работают в любой раскладке). Игрок меняет основную клавишу действия; дополнительные клавиши по
умолчанию (стрелки рядом с WASD, «+»/«−» на цифровом блоке) остаются, если не отданы другому действию.
Одна клавиша никогда не принадлежит двум действиям: при назначении занятой клавиши прежнее действие
остаётся без клавиши, и экран говорит об этом. Esc зарезервирована — она отменяет и открывает меню,
поэтому из игры нельзя «запереться». Подсказки интерфейса показывают текущие клавиши.

## Цвета карты (доступность)
`scripts/ui/color_access.gd`. Режимы: обычные, дейтеранопия, протанопия, тританопия, высокий контраст.
Для нарушений цветового зрения цвет каждого государства **дальтонизируется**: моделируется, как его
видит человек с этим нарушением (проекция в пространстве LMS, Viénot/Brettel), и потерянная разница
переносится в различимые каналы (Fidaner и др.). Тест проверяет, что пары «красный/зелёный» для
дейтеранопии и протанопии после пересчёта различаются сильнее, чем до. «Высокий контраст» затемняет
границы и уплотняет заливку (параметры шейдера `border_dark`, `border_alpha`, `fill_alpha`). Кислотный
зелёный радиации остаётся зарезервированным во всех режимах. Меняется только отображение: симуляция
цветов не видит. Пересчитываются палитра карты, плашки зданий, стрелки атак, корабли, ракеты, посылки,
цвета в рейтинге, «Связях» и карточке государства.

## Качество эффектов
0 — низкое (стрелки атак и метки событий; без искр, всплывающих чисел, следов ракет и мелких вспышек,
одно кольцо на взрыв), 1 — среднее (короче следы), 2 — высокое. На симуляцию не влияет.

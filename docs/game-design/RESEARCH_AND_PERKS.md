# Исследования, перки и новые постройки (Phase 2D)

## Модификаторы (`godot/scripts/simulation/modifiers.gd`)
Единая точка, через которую исследования, перки и постройки меняют правила. Для каждого государства
хранится сумма по статам; `*_mult` дают множитель `1 + сумма` (в пределах 0,3…3), `*_add` — прибавку.
Состояние производное (пересчитывается из изученного, перков и построек, не сохраняется).

| Стат | Где действует |
|---|---|
| `gold_mult`, `supply_mult`, `growth_mult` (только положительный рост), `cap_mult`, `upkeep_mult` | `EconomySystem.tick` |
| `attack_loss_mult` (атакующий), `defense_loss_mult` (обороняющийся), `attack_speed_mult`, `defense_speed_mult` | `AttackSystem._process`: потери за тайл и время захвата |
| `retreat_keep_add` | доля войск при отступлении |
| `boat_speed_mult`, `boat_limit_add` | `NavalSystem` |
| `build_cost_mult` | `StructureSystem.cost` |
| `research_mult` | `ResearchSystem.rate` |

## Постройки
Число видов задаётся данными (`data/buildings/buildings.json`); массивы уровней в `SimState` имеют шаг
`Rules.MAX_BUILDING_KINDS = 16`. Сохранения v1 (шаг 6) переводятся миграцией `SaveFormat` v1→v2.

| Постройка | Нужно исследование | Эффект (точно как в коде) |
|---|---|---|
| Исследовательский центр | — | +2 очка исследований/с за уровень |
| Радар | Радиолокация | вражеская высадка в радиусе 60 теряет 30 % войск (`NavalSystem._land`); в 2E — наведение ПВО |
| Авиабаза | Авиация | ваши атаки на тайлах в радиусе 45 несут потери ×0,75 |
| Военная академия | Военная доктрина | атакующие потери −7 % за уровень (до 3) |
| Логистический узел | Логистика | рост войск +8 % за уровень (до 4) |
| Командный центр | Единое командование | +10 % войск при отступлении и +6 % к скорости атак за уровень (до 3) |
| Бункер | Фортификация | укреплённая зона радиусом 16 (как у поста); при захвате переходит целым |
| Электростанция | Электрификация | снаряжение +30 % за уровень (до 3) |
| Военно-морская база (побережье) | Морская доктрина | транспорты +15 % скорости и +1 транспорт за уровень (до 3) |

Закрытая постройка отклоняется с причиной `locked`; панель строительства и подсказка у курсора называют
нужное исследование. Зоны (радар, авиабаза, бункер) показываются слоем зон с легендой.

## Исследования в партии (`research_system.gd`, `data/research/tech_tree.json`)
5 веток (экономика, армия, оборона, логистика, стратегия), 21 технология с ценой в очках,
предпосылками, модификаторами и открытием построек. Очки: 0,6/с базово + исследовательские центры,
× `research_mult`. Одна технология за раз; при переключении прогресс сохраняется. Команда
`Commands.research(owner, tech)`; событие `research_done`. Состояние сохраняется в партии.
Интерфейс: вкладка «Исследования» в левом доке (текущее исследование, время до конца, ветки),
процент текущего исследования на верхней панели, уведомление о завершении.

## Перки профиля (`data/meta/skill_tree.json`, `scripts/meta/skill_tree.gd`)
6 веток (экономика, армия, логистика, оборона, разведка, дипломатия), 24 перка — небольшие
компромиссы: у каждого плюса есть цена (например, «Налоговая реформа»: +5 % золота, −2 % роста войск).
Открываются очками навыков за уровни; есть требование уровня, предпосылки и взаимоисключающие пары
(на 3-м ярусе — выбор одного из двух). Активны только перки в наборе: 2 слота + 1 за каждые 10 уровней
(до 5). Сброс бесплатный. Экран «Древо навыков» показывает суммарное «что изменится в партии».

Перки попадают в партию только через `MatchConfig.player_perks` (при старте новой партии).
**Честный режим** (флажок на экране новой игры) отключает перки у всех, включая ИИ, и даёт +10 %
к наградам. ИИ получает перки своего характера (`personalities.json`, поле `perks`).

## ИИ
- `ResearchPlanner` (`scripts/ai/economy/research_planner.gd`): ветки по характеру (`research_order`),
  поправки на ситуацию (угроза → оборона, война → армия, убыток → экономика, побережье → логистика)
  с весом `exposure_weight` сложности; в первые 10 минут все предпочитают экономику; шум выбора —
  `mistake_rate`. Шум берётся из хэша, а не из ГСЧ бота: иначе выбор исследования «перемешивал» все
  остальные случайные решения бота — это и было причиной провала ИИ при первом включении исследований
  (8 партий: 0 % побед против 50 % без исследований; после исправления — 50 % и 62 %).
- `EconomicPlanner`: новые постройки — только после 3 уровней городов и фабрики и только на излишки
  золота (≥ 2,5× цены), иначе они отбирали деньги у городов.
- Серии `strategic_vs_legacy` (gen:continents:S, 8 ботов, 7000 тиков, с перками): seed 500 —
  победы 50/50 %, земля 13,5/11,4 %, золото 3,03M/1,84M; seed 700 — 62/38 %, 16,0/9,0 %. До Phase 2D
  на тех же сидах стратегический ИИ выигрывал 25 %. Серия `hard_vs_easy` идёт в честном режиме
  (сравнивается качество решений, а не перки): 83/17 %.

## Тесты
`tests/unit/test_research_perks.gd`: закрытые постройки и предпосылки, скорость исследований и
центры, модификаторы техники меняют доход, перки и честный режим (у игрока и ботов), академия снижает
потери, бункер переживает захват, а пост — нет, радар обнаруживает высадку, ВМБ, детерминизм и
сохранение с исследованиями, миграция v1→v2, правила древа навыков.

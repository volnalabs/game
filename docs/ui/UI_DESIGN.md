# Дизайн интерфейса (Phase 2A)

## Принципы
- Тёмная «штабная» палитра, один акцентный цвет темы, цвета ресурсов фиксированы (золото, снаряжение,
  армия, очки исследований, кредиты, опыт). Никаких эмодзи и случайных Unicode-символов: все пиктограммы —
  SVG из `data/ui/icons.json` (Game-icons.net CC BY 3.0 + Tabler MIT, см. `docs/licensing/ASSET_LICENSES.md`).
- Карта — главный экран: панели компактные, сворачиваются, клики по карте никогда не перехватываются
  невидимыми контейнерами (`MOUSE_FILTER_IGNORE` у всех полноэкранных обёрток; регрессия — `tests/ui/`).
- Каждое число в UI берётся из симуляции или JSON-баланса, а не из текста.

## Дизайн-система (`godot/scripts/ui/`)
| Модуль | Назначение |
|---|---|
| `ui_theme.gd` (`UITheme`) | токены: цвета (`BG`, `SURFACE*`, `STROKE*`, `TEXT*`, ресурсы, `GOOD/BAD/WARN`, редкости), отступы `SP_*`, радиусы `R_*`, шкала шрифтов `T_*`; темы из `data/ui/themes.json` (`apply_theme`); фабрики `button/accent_button/ghost_button/icon_button/card/panel/section/stat_row/progress/badge/icon_label` |
| `icon_registry.gd` (`Icons`) | id → текстура: белый SVG растеризуется в нужный размер с учётом масштаба UI и кешируется; цвет — через `modulate` |
| `anim.gd` (`Anim`) | `fade_in`, `slide_in` (учитывает раскладку контейнеров), `pop`, `pulse`; отключаются настройкой `Settings.ui_animations` |
| `components/` | `SidePanel` (заголовок, прокрутка, закрытие), `ToastStack` (до 5 уведомлений) |
| `menu_background.gd` | «живой» фон меню: настоящий матч только из ИИ на сгенерированном мире, медленный дрейф камеры |

## Главное меню
Слева — навигация по разделам «Игра / Прогресс / Прочее», справа — карточки (последняя партия, позже
профиль). Пункт «Продолжить» появляется только при наличии сохранения. Будущие системы добавляют пункты
через `App.add_menu_entry(section, icon, label, state)` и карточки через `App.menu_cards` — экраны,
которых ещё нет, в меню не показываются (никаких кнопок «Скоро»).

## HUD матча (`scripts/ui/hud/`)
| Зона | Модуль | Содержимое |
|---|---|---|
| Верх | `top_bar.gd` | флаг, государство, место, время, скорость (пауза ×0.5 ×1 ×2 ×4), золото/снаряжение/армия с приростом, прогресс победы, меню |
| Слева | `dock.gd` + `hud_panels.gd` | рейка вкладок: Государство, Армия, Экономика, Строительство, Журнал; вкладки регистрируются `dock.register(id, icon, title, builder)` (исследования, оружие, дипломатия, альянсы подключатся так же) |
| Справа | `leaderboard.gd`, `inspector.gd` | рейтинг (сворачивается), инспектор выбранного государства: обзор, экономика, армия, постройки, угрозы, действия (атака, высадка, фокус), отладка ИИ |
| Низ | `command_bar.gd` | доля армии в атаке (Q/E), быстрые постройки с ценой, действия: домой, отвести все армии, скрыть UI |

Скрыть весь интерфейс — Tab или кнопка на панели действий; Esc возвращает его. Панели под курсором не
перестраиваются (клик всегда попадает в ту кнопку, в которую целились).

## Проверки
- `tests/ui/test_hud_panels.gd`: все вкладки дока и инспектора строятся, закрываются, скрытие/возврат UI,
  HUD помещается в 1280×720 и 1920×1080 без наложений, пункты меню не перекрываются, сетка выбора карт
  подстраивает число колонок.
- `tests/ui/test_input_directions.gd`: клики по карте в любом направлении, на любом зуме и у краёв карты.
- Скриншоты: `xvfb-run -a -s "-screen 0 1600x900x24" $GODOT --rendering-driver opengl3 --path godot -s res://scripts/tools/screenshot_cli.gd -- /tmp/shots europe 300`.

## Визуализация на карте (Phase 2B)
Все слои берут данные только из симуляции — ничего «для красоты», что противоречило бы расчёту.

| Слой | Модуль | Что показывает |
|---|---|---|
| Постройки | `rendering/structure_layer.gd` | плашка цвета владельца с иконкой постройки, кольцо прогресса стройки/улучшения (по `done_tick` и `build_ticks`), точки уровней, «всплеск» при завершении (событие `BUILD_DONE`) |
| Призрак постройки | `rendering/ghost_layer.gd` + `ui/components/build_tip.gd` | куда реально встанет заказ (`StructureSystem.preview` — тот же код, что и `try_build`; тест `test_build_preview.gd` сверяет их на всей карте), зелёный/красный, радиус действия, кольца минимального расстояния до соседних построек, отметка улучшения; подсказка у курсора — цена золотом и снаряжением (красным, если не хватает), время, радиус, точная причина отказа |
| Зоны | `rendering/zone_layer.gd` + `ui/hud/zone_legend.gd` | радиусы построек ровно как в бою (`Rules.building_radius`, евклидово расстояние от клетки постройки); Z или кнопка на панели действий; при размещении показываются зоны того же типа; незавершённые — пунктиром; зоны выбранного государства — красноватые; легенда слева внизу |
| Бой | `rendering/effects_layer.gd` | стрелки атак от своей стороны к живому фронту (сглаженная позиция захватываемых клеток `Attack.last_tile`), толщина по числу войск, при отступлении стрелка разворачивается; искры захвата; всплывающие потери атакующего и защитника раз в секунду (для атак игрока и выбранного государства); метки уничтоженных/захваченных построек, отступлений и высадок; транспорты с курсом. Число эффектов ограничено |
| Выбор старта | `gameplay/spawn_advisor.gd` + `ui/hud/spawn_panel.gd` | двухшаговый выбор: наведение показывает земли, которые займёт старт (ровно `SpawnSystem.disk_tiles`), свободную землю в досягаемости (оценка: заливка по суше до 3 радиусов старта), выход к морю, ближайшие государства с войсками и расстоянием, уровень опасности; щелчок выбирает, повторный щелчок / Enter / кнопка подтверждают, Esc отменяет; отказ объясняется (вода, занято, тесно) |

Экспансия в ничейные земли идёт во все стороны, поэтому стрелок не имеет (кроме высадок).

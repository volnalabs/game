# Дизайн интерфейса (Phase 2A)

## Принципы
- Тёмная «штабная» палитра, один акцентный цвет темы, цвета ресурсов фиксированы (золото, снаряжение,
  армия, очки исследований, кредиты, опыт). Никаких эмодзи и случайных Unicode-символов: все пиктограммы —
  SVG из `data/ui/icons.json` (Game-icons.net CC BY 3.0 + Tabler MIT, см. `docs/licensing/ASSET_LICENSES.md`).
- Карта — главный экран: панели компактные, сворачиваются, клики по карте никогда не перехватываются
  невидимыми контейнерами (`MOUSE_FILTER_IGNORE` у всех полноэкранных обёрток; регрессия — `tests/ui/`).
- Каждое число в UI берётся из симуляции или JSON-баланса, а не из текста.

## Дизайн-система (`godot/scripts/ui/`)
| Модуль | Назначение |
|---|---|
| `ui_theme.gd` (`UITheme`) | токены: цвета (`BG`, `SURFACE*`, `STROKE*`, `TEXT*`, ресурсы, `GOOD/BAD/WARN`, редкости), отступы `SP_*`, радиусы `R_*`, шкала шрифтов `T_*`; темы из `data/ui/themes.json` (`apply_theme`); фабрики `button/accent_button/ghost_button/icon_button/card/panel/section/stat_row/progress/badge/icon_label` |
| `icon_registry.gd` (`Icons`) | id → текстура: белый SVG растеризуется в нужный размер с учётом масштаба UI и кешируется; цвет — через `modulate` |
| `anim.gd` (`Anim`) | `fade_in`, `slide_in` (учитывает раскладку контейнеров), `pop`, `pulse`; отключаются настройкой `Settings.ui_animations` |
| `components/` | `SidePanel` (заголовок, прокрутка, закрытие), `ToastStack` (до 5 уведомлений) |
| `menu_background.gd` | «живой» фон меню: настоящий матч только из ИИ на сгенерированном мире, медленный дрейф камеры |

## Главное меню
_Переработано в Phase 2A.3-B — см. раздел ниже._ Исходный вариант: слева — навигация по разделам
«Игра / Прогресс / Прочее», справа — карточки (последняя партия, позже профиль). Пункт «Продолжить» появляется только при наличии сохранения. Будущие системы добавляют пункты
через `App.add_menu_entry(section, icon, label, state)` и карточки через `App.menu_cards` — экраны,
которых ещё нет, в меню не показываются (никаких кнопок «Скоро»).

## HUD матча (`scripts/ui/hud/`)
| Зона | Модуль | Содержимое |
|---|---|---|
| Верх | `top_bar.gd` | флаг, государство, место; ресурсы с подписями и приростом; время, скорость (пауза ×1 ×2 ×4), прогресс победы, меню |
| Слева | `dock.gd` + `hud_panels.gd` | рейка вкладок: Страна, Армия, Финансы, Наука, Журнал (строительство — в нижней панели, Phase 2A.2); вкладки регистрируются `dock.register(id, icon, title, builder)` (исследования, оружие, дипломатия, альянсы подключатся так же) |
| Справа | `leaderboard.gd`, `inspector.gd` | рейтинг (кнопка «Рейтинг · N-е место», по щелчку — топ-5 и вы), инспектор выбранного государства или постройки: обзор, экономика (своя страна / отладка), армия, постройки, угрозы, отладка ИИ |
| Низ | `command_bar.gd` | контекстная панель: обычный режим, строительство, атака (см. Phase 2A.2) |

Скрыть весь интерфейс — Tab или кнопка на панели действий; Esc возвращает его. Панели под курсором не
перестраиваются (клик всегда попадает в ту кнопку, в которую целились).

## Визуализация на карте (Phase 2B)
Все слои берут данные только из симуляции — ничего «для красоты», что противоречило бы расчёту.

| Слой | Модуль | Что показывает |
|---|---|---|
| Постройки | `rendering/structure_layer.gd` | плашка цвета владельца с иконкой постройки, кольцо прогресса стройки/улучшения (по `done_tick` и `build_ticks`), точки уровней, «всплеск» при завершении (событие `BUILD_DONE`) |
| Призрак постройки | `rendering/ghost_layer.gd` + `ui/components/build_tip.gd` | куда реально встанет заказ (`StructureSystem.preview` — тот же код, что и `try_build`; тест `test_build_preview.gd` сверяет их на всей карте), зелёный/красный, радиус действия, кольца минимального расстояния до соседних построек, отметка улучшения; подсказка у курсора — цена золотом и снаряжением (красным, если не хватает), время, радиус, точная причина отказа |
| Зоны | `rendering/zone_layer.gd` | радиусы построек ровно как в бою (`Rules.building_radius`, евклидово расстояние от клетки постройки); Z или кнопка на панели действий; при размещении показываются зоны того же типа; незавершённые — пунктиром; зоны выбранного государства — красноватые |
| Бой | `rendering/effects_layer.gd` | стрелки атак от своей стороны к живому фронту (сглаженная позиция захватываемых клеток `Attack.last_tile`), толщина по числу войск, при отступлении стрелка разворачивается; искры захвата; всплывающие потери атакующего и защитника раз в секунду (для атак игрока и выбранного государства); метки уничтоженных/захваченных построек, отступлений и высадок; транспорты с курсом. Число эффектов ограничено |
| Выбор старта | `gameplay/spawn_advisor.gd` + `ui/hud/spawn_panel.gd` | двухшаговый выбор: наведение показывает земли, которые займёт старт (ровно `SpawnSystem.disk_tiles`), свободную землю в досягаемости (оценка: заливка по суше до 3 радиусов старта), выход к морю, ближайшие государства с войсками и расстоянием, уровень опасности; щелчок выбирает, повторный щелчок / Enter / кнопка подтверждают, Esc отменяет; отказ объясняется (вода, занято, тесно) |

Экспансия в ничейные земли идёт во все стороны, поэтому стрелок не имеет (кроме высадок).


## Phase 2A.1 — визуальная идентичность и понятность

_Оформление карты и HUD пересмотрено в Phase 2A.2 (раздел ниже): подложки построек, синие акценты и док «Стройка» убраны._

### Правила
- Карта — главный элемент: панели плоские (одна поверхность, тонкая линия, радиус 6), без карточек в
  карточках; списки — строками; заголовки разделов — спокойные, без капса.
- Каждый элемент объясняет себя сам: у кнопки есть подпись или подсказка (тест `test_ux_rules`), у
  недоступного действия — конкретная причина (не хватает N золота, нужно исследование «…»), у каждого
  ресурса — название, а в подсказке: что это, откуда берётся, на что тратится, что будет при нехватке,
  как увеличить (`data/help/glossary.json`).
- Подсказки (`HintLayer`, `Hints.attach`) появляются при наведении и при фокусе клавиатуры, не выходят
  за экран. Важные действия подписаны текстом, подсказка лишь дополняет.
- Числа — моноширинными цифрами (`UITheme.font_numbers`), цвет не единственный носитель смысла
  (символ + подпись + цвет).
- Контраст текста на панелях: основной ≥ 7:1, вторичный ≥ 4,5:1, слабый ≥ 3:1 (проверяется тестом).

### Семейства значков
| Семейство | Источник | Где | Размеры |
|---|---|---|---|
| Символы зданий `b_*` и ресурсов `r_gold`, `r_supplies`, `r_army`, `r_research`, `r_land`, `r_upkeep` | собственные (`Symbols`, `data/ui/symbols.json`) | карта, меню строительства, быстрая стройка, призрак, инспектор, подсказки, справочник | 12–44 px, три уровня детализации |
| Интерфейсные действия `ui_*` | Tabler (линейные) | кнопки, вкладки, панели | 14 / 16 / 18 / 20 px |
| Игровые понятия и мета `g_*`, `m_*`, `w_*`, косметика | Game-icons.net | меню прогресса, достижения, кейсы, косметика | 16–48 px |

`Icons.tex(id)` сам выбирает собственный символ для `b_*`/`r_*`, поэтому одно и то же здание везде
выглядит одинаково.

### Новые элементы
- Верхняя панель: ресурсы с подписями и скоростью изменения, щелчок открывает нужную панель.
- Левый док: подписанные кнопки (Страна, Армия, Финансы, Стройка, Наука, Журнал).
- Меню строительства по группам (Экономика, Армия, Оборона, Наука и логистика) с причиной
  недоступности; при размещении — полоса подсказок управления над командной панелью.
- Здания на карте: наведение — краткая подсказка, щелчок — страница здания в инспекторе (что даёт,
  уровень, стройка, улучшение с ценой или причиной отказа), зона здания на карте.
- Советы новичку (`data/help/tips.json`): один раз при первой встрече с механикой, «Подробнее»
  открывает статью, отключаются в настройках или кнопкой на самой подсказке.
- Справочник (меню, пауза, F1): интерфейс, экономика, здания, армия, исследования, победа; статьи о
  зданиях, технологиях и терминах строятся из данных игры. Категории «Вооружение» и «ПВО» появятся
  вместе с механиками в Phase 2E.

## Phase 2A.2 — светлый спокойный интерфейс и контекстный HUD

Цель — карта главная, интерфейс показывает только то, что нужно в текущей ситуации.

### Палитра (`UITheme`, `data/ui/themes.json`)
Тёплая нейтральная палитра без синего/бирюзового в интерфейсе (карта не перекрашивалась):

| Токен | Цвет | Где |
|---|---|---|
| `SURFACE` | `#24221F` (95 %) | основные панели HUD |
| `SURFACE_2` | `#2D2A26` | кнопки, вторичные поверхности, подсказки |
| `SURFACE_3` | `#38332D` | наведение |
| `STROKE` | `#464038` | разделители (рамки у панелей не используются) |
| `TEXT` / `TEXT_DIM` / `TEXT_FAINT` | `#F2EFE8` / `#B5AEA3` / `#948B7F` | основной, вторичный, подписи |
| `ACCENT` | `#D58B67` | только главное действие экрана и выбранное состояние (тонировкой) |
| `GOOD` / `WARN` / `BAD` | `#83A78A` / `#D2A45F` / `#CF7770` | только для состояний |

Без градиентов, свечений и толстых обводок; панели — скругление 10, без рамки; кнопки — без рамок,
нажатое состояние — тонировка акцентом.

### Контекстный HUD (`hud.gd: mode()`)
| Режим | Когда | Нижняя панель | Справа |
|---|---|---|---|
| обычный | ничего не выбрано | «Сила атаки ≈ N» + доли 10–100 %, «Строительство» (B), «Отступить» — только пока идут атаки | кнопка рейтинга |
| строительство | B / «Строительство» / 1–6 | категории (Экономика, Армия, Оборона, Наука и логистика), «Зоны», «Закрыть»; плитки зданий (символ, имя, цена, клавиша, причина недоступности); справа — краткое описание выбранного здания: эффект, цена · снаряжение · время · радиус, клавиши | — |
| атака | выбрано чужое государство | флаг и имя цели, «отправите ≈ N · у них M», доля армии, «Атаковать» (при общей границе) или «Десант», «Отмена» | инспектор цели |
| постройка выбрана | щелчок по зданию | обычная | инспектор постройки (что делает, уровень, улучшение) и её зона на карте |

Открытие строительства закрывает боковую панель дока и наоборот — одновременно открыт один контекст.
Рейтинг сворачивается сам, пока открыт инспектор.

### Подсказки и уведомления
- Наведение — маленькая карточка (`HintLayer`: имя, одна фраза, 1–2 числа); подробности — только в
  инспекторе после выбора.
- Подсказка у курсора при размещении (`BuildTip`) — одна строка «можно строить» или причина отказа; цена
  показывается в ней, только если не хватает золота или снаряжения.
- Советы новичку (`TipCard`) — один за раз, под верхней панелью, не показываются в режиме строительства
  (кроме совета о строительстве), при выбранной постройке, открытом меню или активном уведомлении.
- Уведомления (`ToastStack`) — одно место, новое заменяет старое, исчезает через 3 с.

### Карта
- Постройки — мягкие закруглённые силуэты (`tools/symbols/make_symbols.py`, v2: скругление контура,
  чуть уменьшенная фигура) без круглых подложек; цвет — светлый тон с примесью цвета владельца, мягкая
  тень. Выбранная постройка — лёгкое светлое пятно и тонкая дуга, наведённая — чуть крупнее.
- Подсветка государства идёт по реальным границам: заливка `fill_alpha 0.40`, выделение — лёгкое
  осветление, граница — тонкая, на тон темнее цвета страны (без белой рамки).
- Зоны — только при выбранной постройке, при размещении или в режиме «Зоны»; заливка 4–8 %, контур
  без дополнительных рамок, тёплые цвета по типу здания.
- Названия государств — средний вес шрифта и тонкая мягкая обводка.

## Phase 2A.3-A — читаемость зданий на карте

Каждое здание рисуется четырьмя слоями (`rendering/structure_layer.gd`), без подложек и колец:

1. мягкая тень со смещением вниз (не свечение);
2. тонкий тёмный контур `#1C1A17` — запечён в варианты символов `map_far/map_full/map_near`;
3. светлый силуэт `#F4F1EA` — одинаковый у всех владельцев, поэтому тип определяется формой, а не цветом;
4. мелкие детали (окна, ворота, иллюминаторы) — тёмный оттенок цвета владельца (`det_full/det_near`,
   контраст с силуэтом ≥ 3.5:1).

Силуэты переработаны так, чтобы внешние контуры не повторялись: город — три отдельные башни, пост —
щит, научный центр — круглая колба, логистический узел — грузовик, командный центр — штандарт с
раздвоенным флагом, электростанция — молния, военно-морская база — якорь (корабли показываются на
воде). Тест `test_map_symbols.gd` сравнивает маски силуэтов всех пар на размерах 20 и 26 px
(наибольшее перекрытие сейчас ≈ 0.70, порог 0.72).

| Масштаб | Размер на экране | LOD |
|---|---|---|
| вся карта (z ≈ 1) | 18 px (минимум) | `far` — только силуэт с контуром |
| обычная игра (z ≈ 3) | ≈ 29 px | `full` — силуэт + детали цвета владельца, точки уровня |
| близко (z ≥ 5) | до 48 px | `near` — дополнительные детали |

Если символы перекрылись бы на экране, здания группируются: рисуется самое важное (город, порт, база…)
со счётчиком «+N»; выбранное и наведённое здание всегда показываются отдельно.

Состояния: обычное — спокойный светлый силуэт; наведение — чуть крупнее и белее; выбор — тонкий
акцентный контур `#D58B67` вокруг силуэта и зона действия (слой зон). Строящееся здание полупрозрачно,
с тонким кольцом прогресса.

Проверка: `scripts/tools/buildings_sheet_cli.gd` — все 15 типов на шести цветах территорий (светлый,
тёмный, зелёный, жёлтый, серый, синий) на трёх масштабах, плотная застройка и состояния наведения/выбора.

## Phase 2A.3-B — главное меню «Живая стратегическая карта»

Меню построено вокруг карты (`scripts/ui/screens/main_menu.gd`, `scripts/ui/menu_background.gd`).

**Карта.** Фирменный мир VolnaLabs — сгенерированный мир «Континенты» с постоянным seed (одинаковый при
каждом запуске), на котором идёт настоящая партия ИИ. Рисуется теми же слоями, что и матч:
территории, здания (2A.3-A), названия государств, стрелки атак и корабли. Первые минуты партии
прокручиваются в пределах ~8 мс за кадр, поэтому при первом открытии видно, как государства растут, а
частота кадров не падает. Мир сохраняется между заходами в меню. Камера плавно переходит между
крупнейшими государствами (каждые ~16 с) и смещена вправо, чтобы блоки меню не закрывали действие.
Читаемость текста обеспечивают мягкие затемнения у левого и нижнего краёв; остальная карта не
затемняется и не размывается.

**Композиция** (асимметричная, без вертикального столбца):

| Место | Содержимое |
|---|---|
| слева вверху | знак VOLNA (три волны, вектор) и надпись «МИРОВАЯ СТРАТЕГИЯ» |
| справа вверху | тихая навигация на плашке: Справочник, Настройки, Титры и лицензии, Выход |
| слева внизу | главное решение: карточка «Продолжить партию» (карта, государство, время, клетки) с акцентной кнопкой «Продолжить», ниже «Новая партия»; без сохранения «Новая партия» — единственная акцентная кнопка; ссылки «Загрузить» и «Генератор миров» |
| справа внизу | командующий: карточка профиля (аватар, звание, уровень, кредиты, кейсы) и плитки коллекции — Прогресс, Навыки, Кейсы, Инвентарь, Награды |
| внизу по центру | строка лицензии «© OpenFront and Contributors …» (AGPL §7) |

Новые пункты по-прежнему подключаются через `App.add_menu_entry(section, …)`: `play` — в ссылки под
«Новой партией», `progress` — в плитки коллекции, `info` — в верхнюю навигацию.

**Отклик.** При наведении и фокусе кнопка или плитка слегка увеличивается (2.5 %, 0.14 с), иконка
плитки окрашивается акцентом, появляется подсказка с полным названием. Блоки появляются коротким
затуханием; при выключенных анимациях всё мгновенно. Постоянного движения нет, кроме самой карты.

**Проверка.** `scripts/tools/menu_shots_cli.gd` — меню в 1280×720, 1366×768, 1600×900, 1920×1080 без
сохранения и с сохранением, плюс состояние наведения (запуск с временным `XDG_DATA_HOME`).
Тест `tests/ui/test_main_menu.gd`.

## Phase 2A.3-C — стрелки атак

Геометрия — `scripts/rendering/attack_arrow.gd` (`AttackArrow`, чистые функции), отрисовка —
`EffectsLayer._draw_arrows` (без отдельных Node: все стрелки рисуются в одном `_draw`, не больше
`MAX_ARROWS`).

Форма: плавная квадратичная кривая от своей стороны к живому фронту (сглаженная позиция захватываемых
клеток), сужающийся корпус — тонкий скруглённый хвост, расширение к середине, компактный наконечник со
слегка отведёнными назад «крыльями»; тонкая тёмная подводка для контраста. Ширина — по числу войск
(логарифм, 2.5–7.5 px на экране), длина — 7–46 клеток в зависимости от масштаба. Хвост догоняет нужную
точку плавно, поэтому при смене направления стрелка изгибается, а не прыгает. Изгиб чередуется по
номеру атаки (влево/вправо), чтобы встречные и соседние стрелки не ложились друг на друга.

| Вид | Как выглядит |
|---|---|
| Наземная атака игрока / выбранного государства | заливка цвета атакующего, по стрелке бежит светлый импульс (направление) |
| Атака на игрока | то же + пульсирующее красное кольцо у острия |
| Десант (`landing`) | начинается от точки высадки на берегу (круглая отметка), дальше — наземное продвижение |
| Отступление | стрелка развёрнута домой, полая (контур + лёгкая заливка), приглушённый цвет |
| Атаки ИИ без участия игрока | тоньше и прозрачнее, скрываются на самом дальнем масштабе |
| Завершённая атака | плавно исчезает за 0.6 с |

Наведение на стрелку (`EffectsLayer.pick_arrow` по тем же точкам, что нарисованы) подсвечивает её и
показывает карточку: «Атакующий → Цель», тип (наземная / десант), атакующий, цель, войска, состояние
(наступает / отступает). Крупных подписей на стрелках нет; число войск на фронте — маленькая метка только
для атак с участием игрока.

Проверка: `scripts/tools/arrows_shots_cli.gd` (наземные, ИИ, отступление, десант, много атак, три
масштаба, наведение); тест `tests/ui/test_attack_arrows.gd`.
